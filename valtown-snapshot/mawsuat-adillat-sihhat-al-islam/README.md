# Welcome to Val Town

Val Town is the simplest way to get code running in the cloud.

This is a basic HTML starter template.

## Picking a starter

| Starter | When to pick it |
| --- | --- |
| **[`basic-html-starter`](https://www.val.town/x/templates/basic-html-starter)** *(you're here)* | Static HTML pages. Sprinkle of vanilla JS. No server-side rendering. |
| [`hono-jsx-starter`](https://www.val.town/x/templates/hono-jsx-starter) | Dynamic server-rendered HTML with JSX. API routes. No React, no SPA. |
| [`react-hono-starter`](https://www.val.town/x/templates/react-hono-starter) | Client-side React SPA with a Hono API backend. |

## Getting started

1. Click `Remix` on this val to get a copy of it
2. Click `main.tsx` to view the website
3. Saves to any file will instantly deploy

### ← main.tsx

This HTTP server hosts all of the other files in this val.

To view your site in a new tab, click on the `...` menu of `main.tsx` to copy
your live HTTP endpoint.

### ← README.md

That's this file, where you can tell people what your cool website does and how
you built it.

### ← index.html

Where you'll write the content of your website.

### ← style.css

CSS files add styling rules to your content.

### ← script.js

If you're feeling fancy you can add interactivity to your site with JavaScript.

### ← favicon.svg

The icon that shows up in the brower tab. Tip: AIs are pretty good at writing
SVG favicons.
